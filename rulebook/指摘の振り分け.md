# 指摘の振り分け

1. その指摘は他のケースにも効くか？ → 効かないなら **ケースだけ直す**（ログには残す）
2. 効くなら原因は？
   - 業務の事実が違う・足りない → **pack**
   - 事実は合っているが、観点・粒度・技法の使い方がおかしい → **rulebook**
   - 項目の抜け・書き方がおかしい → **schema**
3. 判断のコツ：パックに「書いてあったのに使えなかった」→ rulebook か書き方の曖昧さ。「書いてなかった」→ pack。
4. 同じ種類の「ケースのみ」が3回出たら、pack か rulebook へ格上げを提案する。

Claudeは振り分けの**候補と理由**を `proposals/` に出し、人が承認してから反映する。
すべての指摘は `logs/指摘ログ.csv` に記録する。
