# 修正提案

Claudeは pack / rulebook / schema を直接書き換えず、ここに提案を書く。人が承認したら手で反映する。

ファイル名：`YYYYMMDD-<短い名前>.md`

```
## 対象
pack/classes/同値クラス.md

## 種類
追加 / 修正 / 削除

## 変更内容
（変更前 → 変更後）

## 理由と根拠
（出典・日付・確度、きっかけになった指摘ID）

## 影響
（この変更で見直しが必要になるケースやファイル）
```

## 反映のしかた（人が行う）

1. `.claude/settings.json` の該当する deny 行を一時的に外す、または自分で編集する
2. 反映したらコミットし、提案ファイルを `proposals/done/` に移す
3. deny 行を戻す
