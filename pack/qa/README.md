# QAグループの業務知識

商品の仕様書には載っていない「QAの経験知」を置く場所。商品知識と同じく出典・確度を付ける。

| ファイル | 中身 | 例 |
|---|---|---|
| `過去不具合の傾向.md` | 起きた事実 | 「NDC経路の払戻額で端数ずれ（2025-xx 案件名）」 |
| `判断の勘所.md` | ベテランが見るポイント | 「マークアップ変更時は必ず管理画面の表示額も見る」 |
| `問い合わせ先.md` | 領域ごとの詳しい人・チーム | 「LCC直接接続 → ○○チーム」 |

## 置き場所の判断

- 「何が起きたか・どこが危ないか」→ ここ（pack/qa）
- 「だからどう優先度を付けるか・どう設計するか」→ `rulebook/`

聞き取りで得た暗黙知は、話した人と日付を出典として書く。
