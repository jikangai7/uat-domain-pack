# 同値クラス（振る舞いが同じグループ）

クラス分けは「システムが同じ処理をする」という**仮説**。開発に確認できたら確度を「確定」にする。

## 書式

| クラスID | 軸 | クラス名 | 判定条件 | 代表（テストで使う値） | 境界・例外 | 確度 | 出典 |
|---|---|---|---|---|---|---|---|
| C-NDC | 接続方式 | NDC接続 | master の接続方式=NDC | （代表経路ID） | 往路NDC×復路EDIFACT | 要確認 | |
| C-EDI | 接続方式 | EDIFACT接続 | 接続方式=EDIFACT | | | 要確認 | |
| C-LCC直 | 接続方式 | LCC直接接続 | 仕入先=直接 | | | 要確認 | |
| P-ADT | 旅客 | 大人 | 12歳以上（基準日は要確認） | 30歳 | 11歳/12歳 | 要確認 | |

## 無効クラス（弾くべきもの）

| クラスID | 内容 | 期待される挙動 | 確度 | 出典 |
|---|---|---|---|---|
| X-INF超過 | 大人1名に幼児2名 | エラー表示 | 要確認 | |

## クラスをまたぐ組み合わせ（境界として必ず検討）

- 往路と復路で接続方式が違う
- 予約後に経路の設定が変わる
